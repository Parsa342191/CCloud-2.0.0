# CCloud (Personal Fork)

⚠️ این پروژه یک فورک شخصی از برنامه‌ی اصلی [CCloud](https://github.com/code3-dev/CCloud) است.

این نسخه صرفاً با هدف استفاده‌ی شخصی توسعه داده شده و چند قابلیت و رفع‌باگ نسبت به نسخه‌ی اصلی به آن اضافه شده است.

## تغییرات نسبت به نسخه‌ی اصلی (تا نسخه‌ی v2.0.3)

- ✅ **بکاپ‌گیری از لیست پخش (Playlist Backup):** قابلیت Export/Import برای علاقه‌مندی‌ها، گروه‌های پلی‌لیست، و تاریخچه‌ی تماشا از صفحه‌ی تنظیمات
- ✅ **رفع باگ ردیابی فصل‌ها:** در نسخه‌ی اصلی، هنگام تماشای فصل‌های بالاتر از فصل ۱، پیشرفت تماشا با شماره‌ی فصل اشتباه ذخیره می‌شد؛ این مشکل رفع شده و اکنون برنامه هنگام باز کردن یک سریال، خودکار به همان فصلی که آخرین بار تماشا شده می‌رود
- ✅ **ادامه‌ی خودکار پخش (Resume Playback):** موقعیت دقیق پخش هر فیلم/قسمت ذخیره می‌شود و هنگام بازگشت، یک نوار کوچک بالای پلیر با گزینه‌ی «ادامه از X» یا «شروع از ابتدا» نمایش داده می‌شود

## نکات مهم درباره‌ی این فورک

- رابط کاربری (UI/UX) در بیشتر بخش‌های برنامه بدون تغییر نسبت به نسخه‌ی اصلی است؛ تنها تغییر ظاهری، یک نوار کوچک «ادامه‌ی تماشا» در صفحه‌ی پخش ویدیو و صفحه‌ی سریال‌هاست که برای پشتیبانی از قابلیت‌های بالا اضافه شده
- عملکرد و پایداری کلی برنامه همان نسخه‌ی اصلی است
- اشکالات (باگ‌های) دیگر نسخه‌ی اصلی (به‌جز مورد رفع‌شده‌ی بالا) بدون تغییر باقی مانده‌اند

توجه: این پروژه نسخه‌ی رسمی یا اصلی CCloud نیست و به‌صورت مستقل نگهداری می‌شود.
