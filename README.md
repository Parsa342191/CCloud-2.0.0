# CCloud (Personal Fork)

⚠️ این پروژه یک فورک شخصی از برنامه‌ی اصلی [CCloud](https://github.com/code3-dev/CCloud) است.

این نسخه صرفاً با هدف استفاده‌ی شخصی توسعه داده شده و تنها تفاوتش با نسخه‌ی اصلی، اضافه شدن قابلیت **بکاپ‌گیری از لیست‌های پخش (Playlist Backup)** است.

**نکات مهم درباره‌ی این فورک:**
- رابط کاربری (UI/UX) **بدون هیچ تغییری** نسبت به نسخه‌ی اصلی است
- عملکرد و پایداری برنامه دقیقاً همان نسخه‌ی اصلی است
- اشکالات (باگ‌های) احتمالی موجود در نسخه‌ی اصلی، در این فورک هم بدون تغییر باقی مانده‌اند
- تنها تغییر اعمال‌شده، اضافه شدن گزینه‌ی Export/Import برای بکاپ‌گیری از علاقه‌مندی‌ها، گروه‌های پلی‌لیست، و تاریخچه‌ی تماشا است

توجه: این پروژه نسخه‌ی رسمی یا اصلی CCloud نیست و به‌صورت مستقل نگهداری می‌شود.

## سرورها و زیرساخت
این فورک از همان سرورها و زیرساخت نسخه‌ی اصلی CCloud استفاده می‌کند و سرور مستقلی برای آن راه‌اندازی نشده است.

برای دریافت نسخه‌ی اصلی و رسمی برنامه و مشاهده‌ی آخرین تغییرات، لطفاً به ریپازیتوری سازنده‌ی اصلی مراجعه کنید:

👉 ریپازیتوری رسمی CCloud: https://github.com/code3-dev/CCloud
